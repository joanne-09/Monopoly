# Monopoly Game
A multiplayer Monopoly game implemented in TypeScript and Cocos Creator.

## Introduction
This project is a digital version of the classic board game Monopoly, allowing multiple players to compete in playing mini-games. The game is built using TypeScript for the game logic and Cocos Creator for the game engine and user interface.

### Built With
- [TypeScript](https://www.typescriptlang.org/) - Programming language used for game logic.
- [Cocos Creator v3.4.8](https://www.cocos.com/en/) - Game engine used for building the game.
- [Node.js](https://nodejs.org/) - JavaScript runtime for development and build processes.
- [npm](https://www.npmjs.com/) - Package manager for JavaScript.
- [Python](https://www.python.org/) - Used as helper scripts for various tasks.
- [Firebase](https://firebase.google.com/) - Backend services for hosting and real-time database.

## How to Play
1. Player Registration: Players can register or log in to the game in HomeScene.
2. Avatar Selection: Players can choose their game character locally.
3. Matchmaking: Players can join a game room and wait for other players to join universally.
4. Game Start: Once all players are ready, the game starts with a countdown.
5. Turn-Based Gameplay: Players take turns rolling the dice and moving their characters on the board.
6. Mini-Games: Players may land on special tiles that trigger mini-games.
7. Store: Players can visit the in-game store to purchase items using in-game currency.
8. Player Position: The game tracks each player's position on the board after clicking the avatar icon.
9. Game End: The game ends after a set number of rounds or when a player reaches a specific score.
10. Leaderboard: Players can view the leaderboard to see their rankings.

## Features
- Multiplayer support for multiple players to join and play together.
- Game characters with unique abilities.
- Real-time Matchmaking system.
- Turn-based gameplay mechanics with dice rolls.
- Various mini-games integrated into the Monopoly gameplay.
- Store system for purchasing in-game items.
- Tracking of player's position on the board.
- Score tracking and leaderboard.

## Getting Started
[Game Link](https://monopoly-f242d.web.app/)

To get started or contribute to the Monopoly game, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/joanne-09/Monopoly.git
   cd Monopoly
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

3. Open the project in Cocos Creator.

4. Run the game:
   - Click on the "Play" button in Cocos Creator to start the game.
